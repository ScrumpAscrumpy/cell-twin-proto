# Data

The demo video is **not committed** to this repository (it is a ~5 MB third-party asset).
Download it before running `src/video_pipeline.py`:

```bash
curl -L -o deepcell_raw_docs.gif \
  https://raw.githubusercontent.com/vanvalenlab/deepcell-tf/HEAD/docs/images/raw.gif
```

Source: [DeepCell](https://github.com/vanvalenlab/deepcell-tf) `docs/images/raw.gif`
(public demo asset; see the upstream repository for licensing).

The static GitHub Pages site uses pre-extracted frames in `docs/assets/frames/`,
so it works without this file.
