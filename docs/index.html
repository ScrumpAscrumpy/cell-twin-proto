01 / Overview

四层骨架，一条闭环

目标不是“画一个像细胞的动画”，而是让模型持续被数据约束，并能反过来告诉你：哪里缺了机制。

01

单细胞孪生

每个细胞带一个看不见的胞内运动驱动 s，按 s0 / tau_s / alpha 随局部拥挤度自适应。

02

群体 ABM

细胞间有极性对齐、短程排斥和密度反馈；从真实第一帧初始化，而不是随机撒点。

03

参数反演

只给 23 个群体统计量，用随机搜索 + Nelder-Mead 拟合，并用不同密度/时间做 held-out 检验。

04

可辨识性

对比孤立单细胞、单一密度群体、双密度群体、拥挤脉冲四种实验设计下的 loss 面。

合成基准的关键结果： M1（带记忆的拥挤降速）恢复出 (s0, tau_s, alpha) = (1.03, 2.31, 0.72)， 真值为 (1.0, 2.0, 0.8)；M0/M2 差 1–2 个数量级； M3（无记忆）是强竞争者，说明“检测到机制”不等于“唯一识别机制”。

02 / Synthetic benchmark

先证明方法能工作

已知真相的合成数据：先看模型能否选中正确机制，再看它在什么条件下会退化。

白色 × 为真值 (alpha=0.8, tau_s=2.0)。 第一幅在 alpha 方向是平的——孤立细胞看不到拥挤增益； 群体数据给出 alpha–tau_s 权衡谷；拥挤脉冲把 tau_s 拉回真值附近。

03 / Real video check

能跑通，但还不会说谎

一段真实的荧光细胞核延时视频：读帧、分割、追踪、统计、拟合、仿真。结论比“拟合得好”更有价值。

t = 0

这次验证的数字

36使用帧数（每 2 帧取 1）
50初始细胞数
100轨迹数
49长度 ≥ 60% 的轨迹

每帧检出 49–66 个细胞核，中位数 56.5。分割用 Otsu + 连通域，追踪用贪心最近邻；它们只用于 QC 和可视化，拟合用的是不依赖长期轨迹身份的帧级统计量。

模型loss关键参数
关键发现：速度-密度关系的符号相反。 观测到的速度随密度上升（0.24 → 0.37），而 demo 的机制假设是“越挤越慢”。 最优模型是 M3（近似常数速度），不是 M1。这不是代码失败，而是数据质量/观测变量/模型假设不匹配。
为什么不能直接把它当成“仿生成功”？ 检测 Completeness 与密度相关：密集区核更亮、更容易被检出和关联；稀疏区暗核漏检，速度被低估。 再加上“核运动 ≠ 全细胞运动”，以及没有扰动时 alpha–tau_s 的退化， 当前结果只能作为数据质量与可辨识性检查器，不是生物学结论。 详见 VIDEO_REPORT.md。
