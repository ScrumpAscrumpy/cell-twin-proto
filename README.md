# 细胞数字孪生最小原型（Cell Twin Prototype）

一个**纯 NumPy + Pillow、可直接运行**的最小原型，用来验证上一轮讨论里的核心逻辑：

> 单细胞数字孪生 → 群体 ABM → 用群体行为反演胞内机制 → 可辨识性与模型选择

它不是真实显微图像处理系统，而是一个**合成数据上的“方法验证器”**：先用已知真相（ground truth）生成“已录制的群体行为”，再让候选模型去反演，检查能否把缺失的胞内机制找回来、以及在什么条件下找不回来。

---

## 1. 这个原型回答什么

1. **单细胞孪生**：每个细胞带一个胞内状态 `s`（motility drive，运动驱动），它随局部拥挤度自适应。
2. **群体 ABM**：细胞之间有线偏振对齐、排斥、局部密度反馈。
3. **参数反演**：只给群体层面的 summary statistics，拟合四个候选模型，恢复 `s0 / tau_s / alpha`。
4. **模型选择**：比较“无胞内状态”“自适应速度”“拥挤转向”“无记忆速度下降”四种机制，看群体数据能否选中正确的那一个。
5. **可辨识性**：对比
   - 孤立单细胞（free single cell）
   - 单一密度的群体
   - 两种密度的群体
   - 单细胞 + 受控拥挤脉冲（crowding pulse）

   说明“同一套参数在不同实验设计下是否可被唯一确定”。

## 4. 模型

### 4.1 单细胞层（胞内状态）

每个细胞 `i` 有位置 `x_i`、朝向 `θ_i`、胞内运动驱动 `s_i`：

```
ds_i/dt = (s0 - s_i) / tau_s - alpha * rho_i + sigma_s * xi_i
dθ_i/dt = beta * <θ_j - θ_i>_neighbors + sqrt(2 D_r) * eta_i
dx_i/dt = s_i * e(θ_i) + repulsion
```

- `s0`：基线速度；
- `tau_s`：胞内驱动的松弛时间（“记忆”）；
- `alpha`：拥挤对速度的抑制增益；
- `rho_i`：局部密度（邻居数 / 交互面积）；
- `beta`：局部极性对齐强度；
- `D_r`：转动扩散；
- `repulsion`：短程排斥，避免重叠。

**关键点**：`s_i` 是“看不见的胞内状态”。观测只给位置轨迹，不给 `s_i`。

### 4.2 群体层

- 周期边界 2D 盒子；
- 初始条件 `mixed`：70% 细胞在密集团块，30% 在稀疏背景 → 一次模拟覆盖宽密度范围；
- 邻居搜索为 `O(N^2)`，`N=90`，可复现、足够快。

### 4.3 四个候选机制

| 模型 | 机制 | 参数 |
|---|---|---|
| `M0_constant` | 无胞内状态，速度恒定 | `s0` |
| `M1_adaptive` | **真实机制**：带记忆的拥挤降速 | `s0, tau_s, alpha` |
| `M2_turning` | 替代机制：拥挤增加转向，速度不变 | `s0, gamma_turn` |
| `M3_instant` | 无记忆降速：`s = s0 - alpha*rho` | `s0, alpha` |

`M1` 与 `M3` 的稳态速度-密度关系几乎一样，区别在**响应滞后**；这正是“群体数据能否识别记忆”的关键。

---

## 5. 反演与模型选择

### 5.1 观测（summary statistics）

从模拟轨迹中提取 23 个统计量：

- 速度-密度曲线（7 个密度 bin）；
- 局部极性对齐度；
- 对关联函数 `g(r)`（6 个壳层）；
- MSD（4 个时间滞后）；
- 速度自相关；
- 速度-密度滞后互相关（lag 0/1/2）；
- 密度对比度。

观测噪声用 4–6 个随机种子的标准差估计，并设下限，避免对噪声过拟合。

### 5.2 拟合

- 目标函数：标准化残差平方均值（高斯负对数似然，忽略常数）；
- 优化：随机搜索 + 有界 Nelder-Mead（无导数，适合低维、带噪声目标）；
- 四个模型并行拟合；
- 用**留出条件**（不同 `N`、不同 `T`、不同种子）评估外推。

### 5.3 模型选择

比较 train loss 与 held-out loss。`M0`/`M2` 应明显失败；`M1`/`M3` 可能接近——这本身就是一个重要结果（见下）。

---

## 6. 可辨识性实验

四个面板共用同一组 `(alpha, tau_s)` 网格：

1. **single cell, free**：`N=1`，无邻居。`alpha` 完全不可辨识（loss 对 `alpha` 平坦）；`tau_s` 只能从速度噪声的微弱自相关中弱识别。
2. **population, 1 density**：`N=90`。速度-密度曲线 + 对齐 + `g(r)` 提供信息，但 `alpha` 与 `tau_s` 存在权衡（trade-off）。
3. **population, 2 densities**：`N=70` + `N=120`。增加密度条件，检验能否收窄权衡。
4. **single cell + crowding pulse**：`N=1`，在 `t∈[6,13]` 施加外部拥挤 `rho_ext=0.4`。速度先下降再恢复；下降幅度约束 `alpha`，恢复时间约束 `tau_s`。这是**用实验设计打破退化**的最小示例。

---

## 7. 结果

### 7.1 参数恢复（完整运行）

真值：`s0=1.0, tau_s=2.0, alpha=0.8`。

| 模型 | 参数个数 | train loss | held-out loss | 拟合参数 |
|---|---|---|---|---|
| `M0_constant` | 1 | 67.83 | 58.08 | `s0=0.649` |
| `M1_adaptive` | 3 | **0.847** | **0.415** | `s0=1.031, tau_s=2.310, alpha=0.718` |
| `M2_turning` | 2 | 26.92 | 41.15 | `s0=0.718, gamma_turn=5.452` |
| `M3_instant` | 2 | 1.113 | 0.683 | `s0=0.986, alpha=1.457` |

- `M0`（无胞内状态）和 `M2`（拥挤转向）比 `M1` 差 **1–2 个数量级** → 群体数据明确检测到“拥挤依赖的速度机制”。
- `M3`（无记忆降速）是 `M1` 的强竞争者：它的稳态速度-密度曲线几乎一样，train/held-out 只差约 1.3–1.6 倍。
- `M1` 恢复出 `tau_s≈2.31`、`alpha≈0.72`，与真值 `2.0/0.8` 接近 → 多起点优化下，群体统计量足以近似识别胞内参数。

### 7.2 可辨识性（9×9 loss 面）

| 实验设计 | `(alpha, tau_s)` 最优点 | 解读 |
|---|---|---|
| 孤立单细胞（free） | `(0.05, 0.89)`；`alpha` 方向完全平坦 | 没有邻居 → 拥挤增益不可辨识；`tau_s` 只能从速度噪声弱识别 |
| 群体，单一密度 | `(0.71, 2.65)` | 出现一条 `alpha–tau_s` 权衡谷；最优点已接近真值 |
| 群体，两种密度 | `(0.71, 2.65)` | 谷变窄，但 9×9 网格上最优点未移动 |
| 单细胞 + 拥挤脉冲 | `(0.71, 2.06)` | 脉冲的“下降幅度 + 恢复时间”把 `tau_s` 拉回真值附近，谷明显收窄 |

`fig4_identifiability.png` 直接对应这张表：第一幅是水平条带（`alpha` 不可辨识），第二/三幅是斜向的权衡谷，第四幅是脉冲条件下的局部最小值。

### 7.3 关键结论

1. **群体数据能“检测”缺失机制**：`M0/M2` 被明确排除。
2. **群体数据能“粗略识别”参数**：`M1` 恢复出接近真值的 `(s0, tau_s, alpha)`。
3. **但存在机制退化**：`M3`（无记忆）在只给群体统计量时仍然很有竞争力。
4. **扰动能打破退化**：拥挤脉冲下，`M1` 的指数恢复曲线明显优于 `M3` 的阶跃响应；`tau_s` 从 2.65 拉回 2.06。
5. **所以反演协议必须包含“实验设计”这一维**，不能只在被动观测数据上做拟合。

> 注意：这些数字来自**合成数据**，且真值已知；它的意义是验证“反演 + 可辨识性”这套方法骨架，而不是给出某个真实细胞类型的参数。

## 8. 这个原型证明了什么、没证明什么

**证明了：**

- 群体层面的 summary statistics 足以**检测**“存在一个拥挤依赖的速度机制”：`M0`、`M2` 的 held-out loss 高 1–2 个数量级。
- 群体数据也足以**粗略恢复参数**：`M1` 拟合出 `(s0, tau_s, alpha)=(1.03, 2.31, 0.72)`，真值为 `(1.0, 2.0, 0.8)`。
- 但**检测到机制** ≠ **唯一识别机制**：`M3`（无记忆）在单一群体条件下仍然很有竞争力（held-out `0.68` vs `M1` 的 `0.42`）。
- 受控扰动（crowding pulse）能进一步收窄 `(alpha, tau_s)` 的退化：`tau_s` 从群体估计的 `2.65` 拉回 `2.06`，且 `M1` 的指数恢复曲线明显优于 `M3` 的阶跃响应。
- 因此，“用群体行为反推胞内缺失机制”是可行的，但**必须把实验设计纳入反演协议**；否则反演是病态的。

**没证明：**

- 没有使用真实显微图像；分割/追踪误差未进入模型。
- 没有 3D 胞内几何、细胞器、物质轨迹；`s_i` 只是一个标量胞内状态。
- 没有细胞分裂、死亡、表型切换。
- 没有真实的细胞间力学/信号通路；对齐和排斥是唯象项。
- 没有做贝叶斯后验/置信区间；loss 面是剖面，不是完整后验。

## 9. 下一步（按优先级）

1. **换真实数据**：用 Cell Tracking Challenge / Allen Cell Explorer / 光片类器官数据，替换合成轨迹；保留同一套 summary statistics 与反演接口。
2. **加胞内结构**：把标量 `s_i` 换成 `(极性、细胞周期、代谢状态)` 向量，或接一个小的 neural ODE。
3. **加 perturbation 条件**：药物/基因敲除/压缩-释放，做“known-answer test”（隐藏一个机制，看能否找回）。
4. **贝叶斯化**：用 NPE/SBI 或 MCMC 给出后验，而不是点估计；报告可辨识性的置信区间。
5. **3D**：把 2D 盒子换成 3D 球/类器官，接入 3D 分割与追踪。
6. **模型差异项**：引入 Kennedy–O'Hagan 式 discrepancy，区分“胞内缺失”与“胞间缺失”。

## 10. 与上一轮研究提案的对应

| 提案中的环节 | 本原型中的实现 |
|---|---|
| 单细胞数字孪生 | 每个 agent 带胞内状态 `s_i` |
| 胞内坐标/内环境 | 局部密度 `rho_i`（最小化的“环境场”） |
| 物质/行为轨迹 | 位置轨迹 + 速度/密度统计 |
| 群体 ABM | 对齐 + 排斥 + 密度反馈 |
| 参数反演 | Nelder-Mead + summary statistics |
| 模型选择 | M0–M3 的 held-out loss |
| 可辨识性 | 四种实验设计的 loss 面 |
| “缺失机制”推断 | M1 vs M3 vs M0/M2 的比较 |

这个原型是“方法骨架”，不是最终系统；它的价值在于把**反演协议**和**可辨识性问题**先跑通，再逐步换入真实图像、真实胞内结构和真实扰动。

## 11. 视频输入验证

见 [`VIDEO_REPORT.md`](VIDEO_REPORT.md)。一句话：

> 这个 demo 已经能对一段真实荧光显微延时视频做“读帧 → 分割 → 追踪 → 统计 → 拟合 → 仿真”，但在示例的细胞核视频上，模型选择偏向“常数速度”，而不是“拥挤降速”。原因是视频里测得的速度-密度关系是**正的**，与模型假设相反；这更可能是分割/帧间关联的检测偏差，而不是真实生物学。

运行：

```bash
python src/video_pipeline.py --max-frames 36 --step 2 --size 512
```

输出在 `outputs_video/`，包括：

- `fig_video_overview.png`：观测帧 + 分割点 + M1 仿真 + 长轨迹；
- `fig_video_fit.png`：速度-密度与 `g(r)` 的观测/拟合对比；
- `results.json`：每帧检出数、轨迹数、拟合参数与 loss。

这次验证的价值不在于“拟合得好”，而在于它**诚实地暴露了真实数据进入孪生管线时的三个问题**：检测完整性偏差、核运动不等于细胞运动、以及没有扰动时 `alpha–tau_s` 的退化。下一步应该先换数据/换分割追踪，再谈机制反演。
